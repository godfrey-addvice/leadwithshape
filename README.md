# Leadwithshape

An interactive Symbol Picture Builder for a lighthearted Biblical Leadership reflection activity.

This repository preserves the source of the original Lovable project and provides a static Vite build for free GitHub Pages hosting.

## Development

Run `npm install` then `npm run dev`. Run `npm run build` to generate `dist/`.

## Publishing

Under **Settings → Pages**, choose **GitHub Actions** as the build and deployment source. Pushing to `main` runs the included deployment workflow. The expected URL is https://godfrey-addvice.github.io/leadwithshape/ once deployment succeeds.

The original https://leadwithshape.lovable.app/ remains independent and unchanged.
